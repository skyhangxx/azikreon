# AKIZ Lingua: дизайн-система

Источник истины: ТЗ `AKIZ_Lingua_тз.docx` и пять утверждённых референсных макетов.

## Направление

- Светлый образовательный лендинг с корейскими культурными мотивами.
- Светлая тема фиксирована брендом.
- Карточки: радиус 28px. Основные кнопки: радиус 22px.
- Движение спокойное, только для speech bubbles, сакуры, лепестков и обратной связи UI.

## Типографика

- Основная гарнитура: Montserrat, 400/700/800.
- Имена преподавателей: Cormorant Garamond, 600.
- Не использовать больше двух гарнитур.

## UX

- Touch target минимум 44px.
- Видимый `:focus-visible`.
- `prefers-reduced-motion` отключает декоративное движение.
- Поля формы имеют видимые labels и локальные ошибки.
- CRM success показывается только после положительного ответа backend.
- Все тестовые данные находятся в редактируемой конфигурации.
